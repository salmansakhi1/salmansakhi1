# HBL Branch SD-WAN Migration Support

**Status:** Production Experience — Engineering Team Participation  
**Technologies:** Huawei branch routers, enterprise WAN, migration support, branch connectivity validation.

## Scope and role
Participation in banking branch network migration activities as part of a wider engineering team. Responsibilities included branch router installation and configuration support, connectivity checks, application reachability checks, and troubleshooting during migration.

## Example migration phases
1. Record the existing branch connectivity assumptions and the agreed migration scope.
2. Prepare approved branch router interfaces, routes and management access.
3. Perform the coordinated connectivity cutover.
4. Test WAN paths and access to required business applications.
5. Record any faults or deviations and hand off to the responsible operations team.

These phases are representative engineering considerations, not an assertion of a specific undisclosed bank implementation.

## Boundaries
This case study does not claim ownership of HBL's overall WAN design, SD-WAN controller, commercial carrier details or bank-wide rollout. Diagrams are sanitized, conceptual and non-confidential.
